## What was changed, and when

Modified by Sweetplace (M2R S.r.l.) starting **August 2026**. The commit history of this repository
is generated by a release process and is not the working history; the running record of what
changed is [`addon/CHANGELOG.md`](addon/CHANGELOG.md).

Every source file says which of the three it is, in its own header:

| | Files | Header says |
|---|---|---|
| Inherited and **modified** by us | 35 | origin, licence, modified by Sweetplace 2026 |
| Inherited and left **as we found it** | 34 | origin and licence, nothing more — claiming we modified these would be false |
| **Written by us** | 9 | our copyright, same licence |

The split is not by eye: it comes from comparing this tree file by file against the upstream
repository, ignoring the brand rename (`homeway` → `sweetlink`), which is not a substantive change
and would otherwise count every file as modified.

In substance:

- **The cloud service is a different one.** Everything that reached Homeway.io's servers — the
  handshake, remote access, the assistant integrations, WebRTC — no longer runs against them.
  Remote access is now a per-device Cloudflare tunnel provisioned by our own backend. Where code
  from those paths is still in the tree, it is unreachable, and each such place says so in a
  comment next to it.
- **Telemetry and error reporting to third parties are off.**
- **New: everything about delivering a device to a customer** — hardware-bound registration, the
  claim code printed on the label, email-confirmed ownership, the household accounts on Home
  Assistant, the home position, the login-attempt limit, and the pre-cloning report.
- **The user-facing texts are ours**, rewritten rather than inherited.
